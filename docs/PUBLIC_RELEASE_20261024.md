# Source Release October 24 2026

This release publishes code and compact evidence accumulated after the original queue-coordination sandbox. It does not upload the entire local working directory. The original experiment files and source inputs are preserved locally.

## Included

- Final course paper and slides, searchable extracts, frozen protocols, horizon-spectrum tables, selected mechanism diagnostics, and source snapshots in `course_study/`.
- Later sensor-uncertainty, satellite timing, affine conditioning, basketball, and portfolio-allocation experiment source plus compact reports/configurations. These are exploratory simulations. They do not establish flight certification, real basketball effects, or betting profitability.
- Schematic bridge-fleet and geographic multiscale bikeshare simulation source, dashboard source, fixed hypothetical candidate definitions, aggregate results, ranking sensitivity, validation records, and the demonstrated scenario configurations.
- A source-release hash manifest. This records copies and retained artifacts, not a new replication of every study.

## Excluded From Git

- Multi-gigabyte per-frame CSV traces, raw trip files, cached OSM networks, individual journey replay files, intermediate rendering frames, audio, model weights, local environments, installed Tableau dependencies, and private course material.
- The class RAG's documents and indexes. Its code is in the separate [RAG repository](https://github.com/rbajaj5/assured-autonomy-rag).
- Local user changes outside the selected source release, including an existing deleted movie, are not silently committed or restored.

The manifest identifies large retained local artifacts. A source checkout alone does **not** immediately serve the full linked bikeshare replay: the dashboard needs generated catalogs, geometry, journey logs, and experiment caches. The prior local checkpoint describes the complete local workspace, not files promised by this Git commit. Its original "do not publish" instruction records the earlier task; the user subsequently authorized this source publication. No Canvas submission was made.

## Planning Results and Data Boundaries

April 1-7, 2025 Capital Bikeshare demand remains the established observed source; no newer dataset was substituted. Washington/OSM and synthetic Kaliningrad workloads are not field-validated transport models. Rebuilding geographic data requires respecting source access and redistribution terms. OSM-derived data and third-party material do not acquire this repository's code license merely by being used by the scripts.

The corrected all-open baseline remains distinct from the original sentinel-bug results. Investment comparisons use the corrected existing-open baseline; closure-recovery comparisons use the disrupted baseline. Small mean benefits, variability, and resolution-dependent sign/rank changes are descriptive sensitivity findings, not construction recommendations. Candidate locations remain fixed; combined interventions are unsupported.

The planning movie was recorded from the verified local dashboard. Its route/event simulation is CPU-based; the GPU encoded the MP4. A recorded validation report is historical evidence for that captured configuration, not a claim that all later environments or altered inputs were tested.
