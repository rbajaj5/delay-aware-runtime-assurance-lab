# Neural Hanzi: Six Memory Terms in Drone Landings

Large synchronized landing close-ups now make the timeout/queue-aware
trajectory difference visible. A full 16-drone overview stays underneath.
The conclusion returns to the full fleet after the last landings.

The approximately 3:10 lesson covers exactly six Chinese engineering terms,
each with Mandarin pronunciation, English explanation, pinyin and captions:

- 工作记忆: active task state, a contextual engineering interpretation of working memory
- 会话状态: session state
- 团队记忆: team memory
- 记忆片段: memory fragments
- 观测时效: observation freshness
- 长期记忆: long-term memory

This is a camera/narration revision using the existing MuJoCo Warp CUDA
recordings, not a new experiment. Both cameras and plots use the same measured
state per frame. Session restoration, vendor memory systems, long-term learning,
and human cognition are not tested; analogies are identified explicitly.

Assets: 1080p / 25 fps H.264 MP4 with neural narration and captions, plus SRT.
The complete physics archive remains in release `gpu-fleet-trajectories-2026-10-27`.
Scripts, engineering sources, timing and validation are in
`experiments/20261027_gpu_fleet_scaleup/neural_hanzi/`.

Older movies and experimental results are preserved. Synthetic teaching
demonstration, not hardware validation or a commercial-memory benchmark.
